### Key Architectural Distinctions:
1. **Wren AI vs. Wren Engine:** We tested `wren-engine 0.6.0` (the open-source core Python engine and MDL compiler), **not** the full Wren AI enterprise product (which requires a multi-container Docker deployment with an agent service, Qdrant vector store, and web UI).
2. **Autonomous Agent vs. Query Connection Tests:**
   - **Datus** was the only tool tested with natural-language questions in Day 3. Its smoke tests were full end-to-end agent executions (NL prompt -> LanceDB vector search -> LLM SQL generation -> execution).
   - **ktx** and **Wren Engine** smoke tests were direct SQL execution tests (`ktx sql`, `wren --sql`) to confirm connection and model compilation integrity. They did not test question-answering capabilities.

### 2. Datus
- **Embedding Provider:** FastEmbed ONNX `all-MiniLM-L6-v2-onnx` (free local embedding).
- **Execution Interface:** `PrintModeRunner` headless autonomous agent with `codestral-2508`.
- **Layers Exported:** `layers/datus/olist/` and `layers/datus/appdb/` containing `agent.yml` and LanceDB index artifacts.
- **Verification Mode:** Natural-Language Prompts passed to autonomous agent.

#### olist
- **Smoke 1 (Count NL Prompt):** "How many orders are in the database? Return only the SQL query."
  - Generated SQL: `SELECT COUNT(*) AS total_orders FROM orders;`
  - DB Result: `99441` (Success, 2653 tokens in / 13 out)
